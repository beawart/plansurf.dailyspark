# PlanSurf Daily Spark

A lightweight daily planner for tasks, leave, and carrying work forward. Data is saved in your browser, with optional backup and sync.

## Use

Open `index.html` in a modern browser. Add tasks, track progress, and use the backup controls to export or import planner data. Sign in from the cloud button to sync across sessions.

## Package

The app is a standalone HTML page. Keep `index.html` with this README when sharing or packaging it. No build step is required.
